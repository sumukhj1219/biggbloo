This is a **sample post**. It lives in `content/writings/hello-world.mdx`, and every
`.mdx` file in that folder shows up on the Blogs page automatically, newest first.

## Writing a post

Create a new file in `content/writings`. The filename becomes the URL, so
`my-first-post.mdx` is served at `/writings/my-first-post`. At the top, export its details:

```js
export const metadata = {
  title: "My first post",
  description: "One line that shows under the title in the list.",
  date: "2026-10-24",
};
```

Then write the rest in plain Markdown.

## What you can use

- Headings, **bold**, _italics_ and [links](https://x.com/biggbloo)
- Bulleted and numbered lists
- `inline code` and fenced code blocks
- Images and block quotes

> Sweat the small details.

Since it's MDX, you can also import and drop in your own React components.
